# 審查格式規範

用途：定義合規審判者的回覆格式、對比方式、層級與失敗條件。

---

## 一、回覆流程

1. 第一回：給前／中／後三個位置，附行號，不貼片段。
2. 你選 A（前）／B（中）／C（後）。
3. 第二回：給選中項的上下對比。

---

## 二、第一回格式

| 編號 | 判定 | 前 | 中 | 後 |
|---|---|---|---|---|
| CHK-E-xxx | 待選 | 行號 | 行號 | 行號 |

---

## 三、第二回格式（強制）

```text
CHK-E-xxx｜判定：PASS／FAIL／N/A｜選中：B（中段）

修改後（黑字）：
「{片段 ≤30 字}」@ 第 N 行

修改前（紅字）：
「{片段 ≤30 字}」@ 第 N 行
```

---

## 四、硬規則

| 編號 | 規則 |
|---|---|
| FMT-01 | 對比必須上下排列，禁止左右並排 |
| FMT-02 | 先「修改後」後「修改前」 |
| FMT-03 | 修改後黑字，修改前紅字 |
| FMT-04 | 每段片段 ≤30 字，並標行號或章節 |
| FMT-05 | 顏色不支援時，以「修改後／修改前」標籤區分 |
| FMT-06 | 多項回覆時，每項之間空一行 |
| FMT-07 | 不得只給「已確認」「符合」等無片段描述 |
| FMT-08 | 片段與位置不符即 FAIL |

---

## 五、特殊情況

| 情況 | 修改後 | 修改前 |
|---|---|---|
| 新增內容 | 貼新增片段 | 寫「無」 |
| 刪除內容 | 寫「無」 | 貼刪除片段 |
| 未修改但違規 | 貼違規片段 | 貼同段 |
| 全文搜尋類 | 「掃描 0 處」或命中片段 | 同左 |
| N/A | 寫「不適用」 | 寫「不適用」 |

---

## 六、層級

| 層 | 對比方式 | 追加 |
|---|---|---|
| L1（預設） | 修改前後上下對比 | 無 |
| L2 | L1＋前後對比簡版 | 位置綁內容 |
| L3 | L2＋反向提問 | 貼「應該不存在」的內容 |
| L4 | L3＋改前改後各一組 | 雙向比對 |

---

## 七、升層條件

| 條件 | 升到 |
|---|---|
| 跨檔同步 | L2 |
| 新增／刪除整節 | L2 |
| FSM、狀態、角色邊界 | L3 |
| 規則衝突、豁免條款 | L3 |
| 你要求重複抽查 | L3 |
| 跨檔＋核心規則同時改 | L4 |
| 你明確指定 | 依指定 |

---

## 八、層級規則

| 編號 | 規則 |
|---|---|
| LV-01 | 未特別指示，一律 L1 |
| LV-02 | 符合升層條件即升，取最高 |
| LV-03 | 審判者只能建議升層，須附理由 |
| LV-04 | 你可在任一時點指定層級 |
| LV-05 | 升層須於首行記錄：`CHK-E-xxx｜層級：Lx（理由：…）` |
| LV-06 | 未升層不寫層級，視為 L1 |
| LV-07 | 審判者不得自行升層或降層 |

---

## 九、重複抽查

| 編號 | 規則 |
|---|---|
| RV-01 | 你可要求同一項再給一組前中後 |
| RV-02 | 第二次三個位置不得與第一次全同 |
| RV-03 | 全同 ⇒ 標記「疑似未真讀」，該項改 FAIL 或人工核 |
| RV-04 | 審判者不得拒絕重複要求 |

---

## 十、FAIL 條件

| 條件 | 判定 |
|---|---|
| 左右並排 | FAIL |
| 未分修改後／修改前 | FAIL |
| 片段 >30 字 | FAIL |
| 未標位置 | FAIL |
| 只給無片段描述 | FAIL |
| 修改前後相同卻宣稱有改 | FAIL |
| 重複抽查三次全同 | 標記可疑，人工核 |
