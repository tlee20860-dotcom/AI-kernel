# CHK-E 體系審查項目

用途：體系領域審查項目，供合規審判者逐項核。

---

## 一、核對項目

| 編號 | 情境 | 期望 | 判定 | 來源 | 層 |
|---|---|---|---|---|---|
| CHK-E-001 | 改既有檔案 | 標「基於版本 V: xxx」 | 缺 ⇒ FAIL | R-005、S-004 | L1 |
| CHK-E-002 | 改既有檔案 | 列修改區塊＋宣告「其餘 100% 保留原樣」 | 缺宣告或暗改 ⇒ FAIL | R-005 | L1 |
| CHK-E-003 | 交付內容 | 有表格／清單／標題，無廢話開場 | 大段敘述無結構 ⇒ FAIL | R-007 | L2 |
| CHK-E-004 | 任何檔案 | 全文繁體中文 | 出現簡體字 ⇒ FAIL | R-009 | L1 |
| CHK-E-005 | 交付檔案 | 完整檔，非片段 | 片段或 Patch ⇒ FAIL | R-010、F-007 | L2 |
| CHK-E-006 | 缺實體檔提問 | 首句斷路宣告，零結論 | 有結論或假設 ⇒ FAIL | R-011 | L3 |
| CHK-E-007 | 引入 SOP 未定義技術 | 宣告位置正文首區塊；降級註解已清除；附許可 | 位置錯或缺許可 ⇒ FAIL | R-015 | L3 |
| CHK-E-008 | 結束時含體系或專案檔 | affected 逐目標有 UPDATED 或 MISSING | 漏目標 ⇒ FAIL | R-018 | L2 |
| CHK-E-009 | 修改既有檔 | 標基於版本 | 缺 ⇒ FAIL | S-004 | L1 |
| CHK-E-010 | 體系或跨檔修改 | 列關鍵字、受影響檔、確認不受影響檔 | 缺三項 ⇒ FAIL | S-006 | L2 |
| CHK-E-011 | 任何檔案 | 不含「✅」「已交付」「狀態總表」 | 出現 ⇒ FAIL | K-002 | L1 |
| CHK-E-012 | 任何檔案 | 狀態集 5、詞號連續、跨包指向存在 | 任一不符 ⇒ FAIL | K-003 | L3 |
| CHK-E-013 | md 檔 | 首尾非空行無反引號 | 首尾有反引號 ⇒ FAIL | F-004 | L1 |
| CHK-E-014 | 任何檔案 | EOF 三行齊；內文無重複 Version／Writer | 缺 EOF 或內文重複 ⇒ FAIL | F-005 | L1 |
| CHK-E-015 | 完整檔交付 | 章節數一致；行數差 ≤10 或已註明豁免 | 章節不符或未註明 ⇒ FAIL | F-008 | L3 |

## 二、證據要求

- 格式見 `REVIEW-FORMAT.md`。
- 第一回給前／中／後位置，第二回給上下對比。
- 片段各 ≤30 字。

---

## 三、評分

| 分數 | 意義 |
|---|---|
| 1 | PASS |
| 0 | FAIL |
| N/A | 不適用 |

總分＝PASS 數／（總數－N/A）；任一 FAIL 整體不通過。
